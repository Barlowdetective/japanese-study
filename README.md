# 🎌 日本語 Study — N4/N5

A daily Japanese study PWA powered by Gemini AI.

## Features
- 📚 Vocabulary flashcards + list view (10 words/day)
- 📝 Grammar points with examples (3/day)
- 📖 Reading passage + comprehension quiz
- 🎧 Listening drills with text-to-speech
- ✅ Mixed quiz with scoring
- 🔥 Daily streak tracker
- 🔄 Fresh AI content every day via Gemini

## Setup
1. Get a free Gemini API key at [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. Open the app and enter your key on first launch
3. Study every day!

## Deploy
1. Upload all files to a GitHub repository named `japanese-study`
2. Go to **Settings → Pages** → Deploy from main branch / root
3. App live at: `https://YOUR_USERNAME.github.io/japanese-study`

## Files
- `index.html` — Main app
- `manifest.json` — PWA manifest
- `sw.js` — Service worker
- `icon-192.png` — App icon (192×192)
- `icon-512.png` — App icon (512×512)
- `icon.svg` — Source icon (convert to PNG at svgtopng.com)
